# `assets/` — Static Files, Not Code

Nothing in here is read by any notebook or module (verified before moving) — purely reference
material and legacy output images.

- **`Other files/`** — Figures used while writing the paper (e.g. `12_lead_ecg.png`,
  `feedforward_nn.png`, `small_cnn_alexnet_format.png`) plus `image_paper.ipynb`, a scratch
  notebook for producing them.
- **`Example ECG/`** — Two example raw 12-lead ECG reports in `.mat` format
  (`data_1.mat`, `data_2.mat`) for quick inspection/demoing without touching the full dataset.
- **`accuracy.png`** — A legacy standalone output image from an earlier run
  (`run_experiments/3.7.2_.../main_1d_resnet_typ2_selfeeg_singlelead1.ipynb` writes a file of
  this name as one of its outputs; this is just the leftover copy that used to sit at the
  `MAIN/` root).
